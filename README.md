# flappy_tindeq
Flappy Bird connecting to a tindeq device to make training/warming up like a video game

# Initial set up
## Set up virtual environment
In terminal run "python -m venv venv" - this will make a virtual environment
## Activate venv
run "source venv/bin/activate" in order to activate the virtual environment
## requirement packages
run "pip install -r requirements.txt" after activating the virtual environment to get all packages needed

## Current working model,
Run the "graphic_complete.py" script after ensuring that the tindeq device is turned on and in range. There will be a little bit of initial searching but it should find your progressor automatically. 
Right now no easy way to restart when you lose. Game is still very much a work in progress.
